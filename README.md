# 3D Gesture-Interactive Particle Christmas Tree

An interactive 3D particle Christmas tree built with Python, Pygame, OpenCV, and MediaPipe.

## Features
- **3D Perspective Engine**: Multi-layered glowing pine needles, triple spiral light ribbons, ornaments, rotating 3D particle star, and 8 planetary orbits.
- **Smart Dual-Hand Filtering**: Automatically ignores a stationary hand holding a phone and locks onto the active gesture hand.
- **Gesture Controls**: Open Palm (scatter starfield & control density by distance), Pinch (zoom in on photo), Fist (reassemble tree).
- **Shortcuts**: `Space` (themes), `P` (import photos), `F` (fireworks), `R` (replay intro), `V` (camera preview), `Tab` (fullscreen), `ESC` (quit).

## Download (No Python Required)
Go to the **[Releases](https://github.com/hayden0674/ChristmasTree/releases)** page on the right to download:
- **Windows**: `ChristmasTree-Windows.zip` (unzip and double-click `ParticleChristmasTree.exe`)
- **macOS**: `ChristmasTree-macOS.zip` (unzip and open `ParticleChristmasTree.app`)

## Run from Source
1. `pip install -r requirements.txt`
2. `python3 christmas_tree.py`
